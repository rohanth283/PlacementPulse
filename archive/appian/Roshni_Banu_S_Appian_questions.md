### 1. Coding / DSA / Programming Questions

*   **Question 1 (Custom Problem):** Given a list of player numbers from 1 to `n` that contains exactly one duplicate and exactly one missing number, and a fixed set of teams, each containing certain players.
    1.  Identify the duplicate number in the list.
    2.  Identify the missing number in the list.
    3.  Determine the team status:
        *   "Valid" if both duplicate and missing players belong to the same team.
        *   "Multiple Teams" if they belong to different teams.
        *   "No Valid Team" if they are not in any team together.
*   **Question 2 (Similar to Leetcode – Find First and Last Occurrences of a Number):** Given a sorted list of integers and a target value, find the first and last positions (indices) of the target in the list. If the target is not found, return `[-1, -1]`.
*   **Question 3 (Similar to Leetcode – Insert Interval):** Given a list of non-overlapping time intervals (the schedule) sorted by start time, and a new time interval representing a new session to add. Insert the new session into the schedule so that:
    *   The resulting schedule remains sorted by start time.
    *   Any overlapping intervals are merged into one continuous interval.
